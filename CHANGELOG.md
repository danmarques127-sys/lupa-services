# Changelog

All notable changes to this project are documented in this file.

This changelog reflects **engineering milestones**, not every minor edit.  
The project existed in production **before GitHub adoption** — versioning starts here.

---

## [1.0.0] — Initial Production Baseline

**Status:** Production  
**Release type:** Portfolio baseline / GitHub introduction

This release represents the **current, stable production state** of the  
**Lupa Services & Lupa Painting** website at the moment it was formally versioned on GitHub.

### Added
- Dual-brand static architecture supporting:
  - **Lupa Services (Cleaning)**
  - **Lupa Painting (Painting)**
- SEO-first semantic HTML structure
- Mobile-first, accessibility-aware layout
- Apache `.htaccess` configuration:
  - cache control for static assets
  - compression-ready delivery
- Standardized asset structure under `/assets`
- Architecture documentation (`docs/ARCHITECTURE.md`)
- Production-grade README with engineering overview
- GitHub repository hygiene:
  - `.gitignore`
  - release tagging
  - documentation baseline

### Established
- Clean, predictable routing (`index`, `cleaning`, `painting`)
- Static-first content strategy (no runtime dependencies)
- HTTPS / SSL–ready deployment model
- Hosting compatibility with Apache / cPanel environments

### Notes
- This is **not a prototype or MVP**.
- The website was already live and serving real users prior to GitHub tracking.
- Version `1.0.0` marks the point where the project became **formally documented, versioned, and portfolio-ready**.
