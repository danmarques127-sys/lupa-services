## 🧠 Project Overview

This repository contains the **official production website** for **Lupa Services**, a professional company providing **cleaning and painting services** for residential and commercial clients.

The website was designed to **clearly separate service categories**, showcase real work, and establish a **strong SEO foundation** for long-term organic growth.

This is **not a template or demo project**.  
It is a **real-world client website**, actively used in production.

---

## 🎯 Goals & Strategy

- Clearly distinguish **cleaning** and **painting** services
- Improve local SEO structure and crawlability
- Present services in a professional, conversion-focused layout
- Support future expansion (blog, new service pages)
- Deliver a fast, mobile-first browsing experience

Every technical and structural decision in this project was made with **clarity, performance, and scalability** in mind.

## 🔍 SEO & Optimization

This project includes an **advanced SEO structure** for a static business website:

- `robots.txt`
- Sitemap index strategy:
  - `sitemap-cleaning.xml`
  - `sitemap-painting.xml`
  - `sitemap-hub.xml`
  - `sitemap_index.xml`
- Google Search Console verification
- Clean URLs and semantic HTML hierarchy

This setup improves crawl efficiency and allows independent SEO growth for each service category.
